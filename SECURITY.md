# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues, discussions or pull requests.

Report them privately through GitHub. For a public repository, open its **Security** tab and choose **Report a vulnerability**. For a product whose repository is private, report it the same way on this repository, [Vexatra/.github](https://github.com/Vexatra/.github/security/advisories/new), and name the product.

Include the affected product and version, a description of the impact, and the steps or input that reproduce it.

You will get an acknowledgement within seven days. We will keep you informed while we investigate and fix the issue, and credit you in the advisory unless you prefer otherwise.

## Supported versions

Security fixes are made for the latest release of each product. Before a product reaches 1.0.0, only its newest minor version receives fixes.
